# Security policy

## Supported versions

Only `main` and the site it runs, [agenticlibrary.app](https://agenticlibrary.app), get security fixes. There are no
releases or older versions to patch.

## How to report a vulnerability

Report it privately through GitHub's
[private vulnerability reporting](https://github.com/orhunakkan/agentic-library/security/advisories/new). Please don't
open a public issue, pull request or discussion about it.

Say what's affected, how to reproduce it, and what an attacker could do with it.

## What to expect

Folio has one maintainer. They aim to reply within 7 days, keep you posted while it's fixed, and agree with you when to
disclose it. The default is 90 days after the report, or sooner once a fix is live.

## Scope

In scope:

- the code in this repository;
- agenticlibrary.app.

Out of scope:

- denial of service, and load or volume testing;
- social engineering, of the maintainer or of anyone else;
- scanner output with no demonstrated impact.

## Good faith

Test only against accounts you own. Don't access, change or delete other people's data, and stop as soon as you reach
any. Research done in good faith, within these limits, is welcome.
